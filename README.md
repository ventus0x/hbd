# Secret Birthday Gift — For babe 💖!

A playful, passcode-locked birthday surprise website.

Open `index.html` (or the GitHub Pages link once Pages is enabled) and enter the 4-digit secret passcode to unlock the birthday surprise for babe 💖!

Note: the passcode lock is a fun surprise, not a security feature — anyone who views the page source can find it, so treat it as playful, not private.
